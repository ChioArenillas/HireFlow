# HireFlow

## 🧩 Description

HireFlow is an AI-powered recruitment platform that helps job seekers evaluate how well their CV matches real job opportunities. Users can browse job listings, upload their CV in multiple formats (PDF, DOCX, or TXT), and receive an AI-generated analysis based on the selected role.

The platform uses AI to compare candidate profiles against job requirements, generating a compatibility score, identifying missing skills, and providing personalized feedback to improve job applications. The project focuses on creating a modern SaaS-style experience with real-world AI integration and scalable architecture.

* Next.js

## 🎯 Features

* Browse and explore real job listings
* View detailed information for each job opportunity
* Upload CVs in PDF, DOCX, and TXT formats
* Extract and process CV content automatically
* AI-powered CV analysis using OpenAI
* Match score calculation based on job requirements
* Missing skills detection
* Personalized feedback and improvement suggestions
* Persistent analysis storage using Zustand
* Responsive SaaS-style user interface

## 🧠 Key Concepts

* File uploads and document processing
* AI integration with OpenAI API
* Prompt engineering and structured JSON responses
* State management with Zustand
* API route development with Next.js
* Data persistence and client-side storage
* Responsive UI design with Tailwind CSS
* TypeScript type safety
* Client/server communication in modern React applications
